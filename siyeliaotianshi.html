代理教程

一、创建API key

如果你希望使用自己的 API Key，请前往对应模型的官网创建。

以 DeepSeek 为例，打开 DeepSeek开放平台。

  1. 点击“用量信息”，查看目前的余额。
  2. 如余额不足，则点击“去充值”支付。收费标准实时变化，详见查看 DeepSeek 官方的 产品定价，建议每次充值不超过10元。
  1. 点击“API keys”。
  2. 点击“创建 API key”。创建后你将得到一串“sk-”开头的密匙，请不要分享给任何人。

二、部署API key

回到四叶聊天室，打开“设置”中的“AI代理”。

  1. 选择“API类型”。你获取了什么模型的API key就选择什么，如果你拿到了 DeepSeek 的 API key，就选择 DeepSeek。
  2. 填入“API 地址/Base URL”。选择API类型后会自动填入，无需编辑。
  3. 填入“API key”。请将你刚才复制的 API key 粘贴进输入框。若留空，则使用内置默认 Key。
  4. 填入“模型”。填入你想调用的AI模型，不填则由系统自动选择。

三、测试部署

如果填写了自己的 Key，建议先测试 AI 是否部署成功。

  1. 点击“测试连接”。如果显示“连接成功”，则代表可以正常使用。如果显示“请求失败”，请检查第二步是否有错误。
  2. 点击“保存设置”。保存后关闭设置，就能和冰凛四叶正常聊天啦~
